# YUMI Cosmetics – Theme-Anpassungen

Eigene Sections für die Produktseite (Shopify-Theme „ecom-assets-theme-v2“).

| Datei | Zweck |
|---|---|
| `sections/yumi-main-product.liquid` | Hauptbereich: Galerie mit Badges, Info-Blöcke, Warenkorb, Countdown, Garantie, Akkordeons, Sticky-Leiste |
| `sections/yumi-testimonials.liquid` | Kundenstimmen-Slider mit Vorher/Nachher-Bildern |
| `sections/yumi-image-text.liquid` | Bild mit Text – Vorteile oder Schritte („So funktioniert's“) |
| `sections/yumi-before-after.liquid` | Vorher/Nachher-Slider mit Statistiken |
| `sections/yumi-comparison.liquid` | Vergleichstabelle „Warum YUMI?“ |
| `sections/yumi-faq.liquid` | FAQ (zweispaltig) |
| `sections/yumi-cards.liquid` | Karten (Inhaltsstoffe) |
| `sections/yumi-feature-banner.liquid` | Marken-Banner mit Punkten und Bild |
| `snippets/yumi-icon.liquid` | Gemeinsame Icons |
| `assets/yumi-pdp.css`, `assets/yumi-pdp.js` | Gemeinsames Styling und Verhalten |
| `templates/product.json` | Produkt-Template mit allen Sections |

Alle Texte, Bilder, Farben und Abstände sind im Theme-Editor bearbeitbar.
